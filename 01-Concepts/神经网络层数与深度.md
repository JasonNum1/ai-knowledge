# 神经网络层数与深度

**核心结论**：大模型语境下的"网络"指**神经网络（Neural Network）**——把 N 个结构相同的处理层串成一条流水线。**深度（Depth）= 层数**，**宽度（Width）= 每层的大小**；"深度学习"的深度就是这个字面意思。对后端开发者而言，层像流水线上的工位：深度是工位数量，宽度是单个工位的设备规模。

## 是什么

- **层（Layer）**：一个独立的加工单元。现代大模型（Transformer 架构）的每一层 = 自注意力（Self-Attention，负责跨 token 传递信息）+ 前馈网络（Feed-Forward Network，负责逐 token 加工）。
- **堆叠（Stacking）**：把层串行连接，数据从第 1 层流到第 N 层，每层读入上一层的输出、写出自家的输出。
- **深度**：串行层数 N。**宽度**：每层内部的维度规模（隐状态向量长度）。参数量 ≈ Σ(每层宽度相关的权重数) × 层数。

## 为什么需要：深度是能力的经典来源

- 层数越多，数据被加工的次数越多，模型能表达的变换越复杂、可维持的推理链路越长——大软件工程、多步数学推导这类长链路任务尤其依赖深度。
- Scaling 有两根轴：**加宽**（每层做大，堆参数）与**加深**（层数做多，加计算深度）。二者都涨成本，路线之争在于性价比——Loop 架构走的是"不加深物理层数、加深执行遍数"的第三条路（见 [[Loop Transformer 循环深度]]）。

## 怎么工作

- 数据逐层流动，每层通过读写 [[隐状态与残差流|隐状态]] 完成加工：隐状态进层 → 层内计算 → 增量写回。
- "更深"存在两种含义，读论文时要区分：
  - **物理深度**：实际串行的层数（决定权重存储量）。
  - **等效深度**：数据被加工的总遍数（决定计算量）。Loop 架构物理 28 层、执行两遍，等效 56 层。

## 与后端概念的对应

| 概念 | 后端类比 |
|---|---|
| 层 | 流水线工位 / 责任链上的中间件节点 |
| 深度 | 调用链长度——链越长，单请求经过的加工越多 |
| 宽度 | 单工位的设备规模（线程池大小、缓冲区容量） |
| 物理深度 vs 等效深度 | 部署的实例数 vs 实际执行的重试/迭代轮数 |
